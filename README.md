# 🚀 Tamil Nadu Startup Spatial Innovation Platform (TN-Startup-Map)

An enterprise-grade, Apple Human Interface Design-inspired spatial ecosystem intelligence platform mapping, tracking, and showcasing startups, district innovation clusters, funding rounds, and founder stories across all 38 districts of Tamil Nadu.

---

## ✨ Core Platform Highlights

- 🗺️ **Interactive Spatial GIS Map**: High-performance interactive map clustering verified ventures across Tamil Nadu's 38 districts, tech corridors, and tier-2/3 innovation hubs.
- 🏢 **Multi-Venture Founder Studio**: Unified founder portal with multi-startup switching, curated banner designs, company ownership transfer, and social channel management.
- 📰 **Ecosystem Stories & Insights Platform**: First-person aerospace, deep tech, and SaaS engineering dispatches from verified founders with interactive appreciation claps.
- 🛡️ **Executive Administration & Moderation**: Non-destructive soft-delete architecture, 1-click submission review workflows with auto GPS coordinate resolution, and homepage spotlight pinning.
- 🎨 **Apple Design Foundation**: Glassmorphism materials, micro-animations, high-contrast typography, and full dark-mode compatibility.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend**: Node.js, Express, TypeScript, Prisma ORM, PostgreSQL (with in-memory spatial mirror)
- **Mapping**: Leaflet / React-Leaflet, GeoJSON District Boundaries

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
# Clone the repository
git clone https://github.com/bharani-01/TN-Startup-Map.git
cd TN-Startup-Map

# Install dependencies
npm install

# Build client and server
npm run build

# Start fullstack development environment
npm run dev
```

The application will be available at:
- **Client**: `http://localhost:5173/` (or `http://localhost:5174/`)
- **Server API**: `http://localhost:3001/`
